Responde con tus propias palabras.

1. ¿Qué es una API?

Respuesta: Una API es una interfaz que permite que una página web y un servidor intercambien información.

2. ¿Por qué se dice que una API permite comunicación entre cliente y servidor?

Respuesta: Porque la página web envía solicitudes al servidor y el servidor responde con datos o mensajes mediante la API.

3. ¿Qué hace la ruta GET /api/propuestas?

Respuesta: Obtiene las propuestas guardadas y las envía a la página web para mostrarlas.

4. ¿Qué hace la ruta POST /api/propuestas?

Respuesta: Recibe los datos escritos en el formulario y guarda una nueva propuesta en el servidor.

5. ¿Qué hace express.json() en esta práctica?

Respuesta: Permite que el servidor entienda los datos JSON enviados desde la página web.

6. ¿Qué hace JSON.stringify?

Respuesta: Convierte objetos de JavaScript en texto JSON para poder guardarlos en un archivo.

7. ¿Qué hace JSON.parse? 

Respuesta: Convierte texto JSON en objetos de JavaScript para poder usar la información.

8. ¿Qué hace fs.readFileSync?

Respuesta: Lee el archivo JSON donde están guardadas las propuestas.

9. ¿Qué hace fs.writeFileSync?

Respuesta: Guarda las nuevas propuestas en el archivo JSON.

10. ¿Por qué este ejercicio todavía no es una base de datos?

Respuesta: Porque las propuestas se almacenan en un archivo JSON simple y no en un sistema especializado de bases de datos.

11. ¿Qué significa validar campos antes de guardar una propuesta?

Respuesta: Significa verificar que el usuario complete correctamente los campos importantes antes de guardar la información.

12. ¿Por qué una API comunitaria debe responder con mensajes claros cuando falta información?

Respuesta: Porque ayuda al usuario a saber qué dato falta o qué debe corregir para enviar la propuesta correctamente.
